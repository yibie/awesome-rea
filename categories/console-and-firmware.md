# Console & Firmware

Use this category for AI-assisted reverse engineering that is not a game: console firmware, embedded devices, boot ROMs, drivers, platform compatibility layers that reimplement an OS surface Wine-style, and the tooling around them. The same rule applies as everywhere else — the entry has to name the acceptance test, whether that is a checksum, a boot-to-menu milestone, an emulator run, or a hardware test on a real device.

- [xbox-boot-re](https://github.com/bennyborn/xbox-boot-re) - Firmware: reconstructs the original Xbox boot animation from a single 1 MB retail BIOS image, verified by matching the animation and its state bit for bit against recorded runs in the xemu emulator, down to the sound sequencer's DSP program; its README states that Claude Opus 5.5 produced most of the work under human direction.
- [Champagne](https://github.com/unixzii/Champagne) - Platform layer: runs Snow Leopard applications on macOS and Windows without a virtual machine, Wine-style, verified by a "what works" list rather than a promise - TextEdit is fully usable and Calculator, Stickies, Font Book, Dictionary and the Finder open - and all 28 of its commits carry a `Co-Authored-By: Claude Opus 5.5` trailer.
