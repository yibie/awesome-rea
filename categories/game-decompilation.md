# Game Decompilation

Use this category for matching decompilation of games: projects that rebuild a retail binary into readable source and check the result against the original. The acceptance test is usually byte-exactness — a rebuilt function has to produce the same machine code as the ROM — so entries here should say which counter runs (functions matched, functions byte-exact) and what gates a function before it counts.

What does not belong here: ports that do not claim byte-matching (see Static Recompilation & Native Ports), decompilation of non-game software (see Console & Firmware), and tools rather than projects (see Tooling & MCP).

- [500+ Billion Tokens Later](https://momo5502.com/posts/2026-10-09-game-decompilation/) - Decompilation: agents got 99% of a first-person shooter's functions into the reconstructed source with 83% of them byte-exact, gated by a byte-matching verification harness, and the operational finding was that dropping the context compaction threshold from 90% to 42% saved more than any model upgrade.
- [sm64ds-decomp](https://github.com/tangosdev/sm64ds-decomp) - Decompilation: an agent team rebuilds Super Mario 64 DS function by function against the retail cartridge, with progress tracked per function (11,385 of 11,389 matched) and each match gated by independent byte comparison, a source review gate and a relocation destination audit; the same repository ships a PC port kept honest by a smoke build that has to stay green.
- [Xenosaga Ep I Decompilation Project](https://scientia.godsibb.net/t/xenosaga-ep-i-decompilation-project/1496) - Decompilation: one person reached 3,669 of 7,645 game functions in a little over a week with AI assistance, using matching decompilation as the criterion and an independent byte checker that does not trust the build the agents produce.
- [DecompPipeline](https://github.com/GeneralAtrox/DecompPipeline) - Behaviour-checked decompilation: asks whether a small model (Haiku) can decompile game functions when the agent runs in a locked-down `claude -p` session against Ghidra and an emulator oracle, and stamps every harness with its oracle input so a stale harness cannot pass for a current one.
- [A Link Between Worlds decompilation](https://github.com/7akeem0/albw-decomp-ai) - Decompilation: many LLM agents each take one function of the 3DS Zelda until it compiles to exactly the same bytes, and the progress table separates the 16,544 functions matched (63.7%) from the 882 of those that only matched with a hack.
- [Pokemon HeartGold/SoulSilver single-screen](https://github.com/ClickingMaster/pokeheartgold-single-screen) - Decompilation fork: a single-screen build of the fully decompiled HeartGold and SoulSilver where both ROMs build byte-for-byte, whose README opens by disclosing that nearly all of the fork's changes were written by Claude through Claude Code - and notes that the upstream project does not accept AI-generated contributions.
- [Monster Hunter 2 decompilation](https://github.com/Batenkaitos-dev/mh2-decomp) - Decompilation: rebuilds the boot executable and all 12 code overlays byte for byte, and says plainly that readability work was deliberately deferred until the whole build matched, with a `Co-Authored-By: Claude 5.5` trailer on the commits.
- [Way of the Samurai (PS2)](https://github.com/dnb4ever/way-of-the-samurai-decomp) - Decompilation: AI agents rebuild the PS2 game function by function under a source-patched ee-gcc 2.9, each match gated by an independent byte comparison that compiles the C, links it at the function's real address and requires the bytes to equal the retail binary (score 0 or it does not count); a parallel static-recompilation port built on the same decompilation already boots the recompiled Emotion Engine code to its first rendered frame.
- [gagarin](https://github.com/r-melvin/gagarin) - Decompilation: rebuilds the Red Alert 2 / Yuri's Revenge engine, with a README that draws the line the whole field needs - function matching and successful compilation do not prove behaviour.
- [civ2](https://github.com/richardpenman/civ2) - Reconstruction: Civilization II turned into portable C++ that builds on Linux, macOS and Windows and is proven by matching screens pixel for pixel - 25 of 29 recorded scenarios match exactly, and the README says where the other four differ.
- [IGI-RE](https://github.com/slickdaddyy/IGI-RE) - Decompilation: Project I.G.I. from 2000 rewritten as readable C one verified function at a time, which is the acceptance criterion stated in its first paragraph.
