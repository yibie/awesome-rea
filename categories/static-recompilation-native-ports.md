# Static Recompilation & Native Ports

Use this category for projects that turn a released binary into a program that runs natively on another platform — static recompilation, or a port built on top of a matching decompilation. These rarely promise byte-exactness; what they promise instead is that the game is playable and does not behave differently. So the acceptance test is what the entry has to name: a comparison against the original ROM, a required hash match on the user's own dump, a compatibility matrix, or frame-time measurements.

What does not belong here: projects whose counter is byte-exact function matching (see Game Decompilation), and emulators, which do not reimplement the game at all.

- [goldeneye-pc-port](https://github.com/jkdansereau/goldeneye-pc-port) - Native port: two coding agents ported a matching decompilation of GoldenEye 007 to PC in 43 days, verified by byte comparison against the original ROM plus a porting-notes log that requires every recurring bug class to be written back before it is considered closed.
- [BattleShip](https://github.com/vinvirile/BattleShip) - Native port: a Super Smash Bros. port its author describes as 100% AI-generated over 25 days with Opus 4.6/4.7 and GPT 5.5, verified by requiring the user's own ROM dump to match a known hash, and shipping no Nintendo assets at all.
- [ssbu-recomp](https://github.com/Denkishi/ssbu-recomp) - Static recompilation: Super Smash Bros. Ultimate 13.0.4 rebuilt as a native Windows program with Vulkan rendering, verified by a per-mode compatibility matrix that marks modes "works", "tested with scripted input only" or "not tested", plus frame-time measurements including a whole match at 59-60 fps on an integrated GPU.
- [VandalHearts-decomp](https://github.com/HalmyLyseas/VandalHearts-decomp-SLPM-86007) - Native port: Vandal Hearts rebuilt for PC on top of a byte-exact matching decompilation, so the port inherits the decompilation's byte comparison as its correctness check.
- [KartPad](https://github.com/chrissotraidis/kartpad) - Native port: Mario Kart Wii and Retro Rewind running natively on iOS, iPadOS, macOS, tvOS and Android, verified by requiring a legally obtained PAL `RMCP01` revision 0 image and by build, test and device records, and its README discloses substantial AI assistance with no audited percentage of generated code.
- [diehard-stv-decomp](https://github.com/dnb4ever/diehard-stv-decomp) - Static recompilation: AI agents statically recompile Die Hard Arcade / Dynamite Deka (Sega ST-V, dual Hitachi SH-2) to C++ and reconstruct its game logic as equivalence-faithful C, with byte-matching ruled out because the 1996 Hitachi SHC compiler build is lost, so correctness is gated by semantic 0-diff validation of the recompiled functions against an SH-2 interpreter oracle plus a compile-clean equivalence bar for the hand-decompiled C, all run against the user's own reconstructed cart dump.
- [Precursor](https://github.com/thebardockgames/Precursor) - Native port: an unofficial Android ARM64 port of Jak and Daxter built on the decompilation, whose README states that the fork is developed with AI help and that commits are marked `(AI-assisted)`, and warns that none of it has been verified end to end.
- [Railroad Tycoon 2 in Rust](https://github.com/pedryvo/rrt2-decomp) - Native reimplementation: reverse engineering and a modern Rust rewrite of the game, with twenty of its recent commits carrying an AI co-author trailer.
- [Mario Strikers Charged on PS Vita](https://github.com/CBOC-Vita-Lab/strikers-charged-vita) - Native port: Mario Strikers Charged running on the PS Vita with no emulation involved, across four thousand files whose commits carry AI co-author trailers.
- [Glassline](https://github.com/MoonCellar-Team/Glassline) - Native port: the 2010 iPad build of Mirror's Edge running on Linux, with an AI Disclosure section that names Claude Code outright rather than leaving it to the commit history.
- [SegaSonic The Hedgehog native port](https://github.com/cheviman/segasonic-port) - Native port: the 1993 System 32 arcade game's own program decompiled into C and built for Windows, Linux, macOS, Switch and Android - explicitly not an emulator - with AI participation recorded only in twenty commit trailers.
- [mugen-unleashed](https://github.com/zxmarcos/mugen-unleashed) - Reconstruction: the M.U.G.E.N 1.1 Beta 1 engine recovered from its original 2013 executable into C that builds a native mugen.exe running the game the way the original does, shipping no game data and none of Elecbyte's files, with AI participation recorded in the commit trailers rather than the README.
- [COGBox](https://github.com/Shagg88/COGBox) - Native port suite: a launcher for native Windows versions of Gears of War 2, 3 and Judgment that unpacks your own copy of each game, checks it is the right release, and starts it, with AI participation recorded in thirty-six commit trailers.
- [Echoes Unbound](https://github.com/Odrannnn/MetroidPrime2Port) - Native port: Metroid Prime 2 for Linux, Windows, macOS, Android and experimental iOS, across six thousand files, with a Linux build running in CI and the first alpha scheduled for release.
